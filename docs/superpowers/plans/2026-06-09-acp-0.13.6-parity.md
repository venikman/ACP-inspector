# ACP 0.13.6 Stable Parity — Implementation Plan (Phase 1, Plan 1 of 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the F# ACP implementation from pinned schema `0.11.3` to stable parity with ACP `0.13.6` by adding the seven newly-stabilized features, fixing three latent defects, the CI drift bug, and the trust-doc lag — with the full test suite green.

**Architecture:** Each feature is a vertical slice across the three holons in fixed order — **domain** (`protocol/src/Acp.Domain.fs`) → **codec** (`runtime/src/Acp.Codec.AcpJson.fs` + `runtime/src/Acp.Codec.Types.fs`) → **connection** (`runtime/src/Acp.Connection.fs`) → **protocol state machine** (`protocol/src/Acp.Protocol.fs`) → **sentinel** (`sentinel/src/Acp.Validation.fs`) → **tests** (`sentinel/tests/`). New capability fields are nullable **marker objects** (mirror the existing `SessionListCapabilities option`), never bools. New wire fields are **omit-when-empty/None** so existing 0.11.x payloads still round-trip byte-for-byte.

**Tech Stack:** F# on .NET 10 (`global.json` pins `10.0.101`); xUnit 2.6.6 + FsCheck 3.3.2; single test project `sentinel/tests/ACP.Tests.fsproj`; Fantomas formatting gate. All shapes in this plan were verified against `schema/schema.json` @ tag `v0.13.6` (raw `jq`).

## Conventions (read once)

**The F# TDD loop used throughout.** F# is whole-program compile-checked, so adding a DU case or record field breaks compilation everywhere it's matched/constructed until you fix every site — that compile failure *is* your first "red". The loop per task:

1. **Write the new test(s)** referencing the target types/shape. The project will not compile (types/fields don't exist) → **red**.
2. **Add domain types/fields**, then fix every compile error the recipe enumerates (codec arms, method maps, construction-site literals).
3. **Build:** `dotnet build ACP-inspector.slnx -c Release` → must compile.
4. **Run the focused test(s)**, then the suite → **green**.
5. **Format:** `dotnet tool restore && dotnet fantomas protocol/src runtime/src sentinel/src sentinel/tests cli/src cli/apps` (no `--check` to apply).
6. **Commit.**

**Commands:**

- Build all: `dotnet build ACP-inspector.slnx -c Release`
- Full suite: `dotnet test sentinel/tests/ACP.Tests.fsproj -c Release`
- Focused: `dotnet test sentinel/tests/ACP.Tests.fsproj -c Release --filter "FullyQualifiedName~Codec"`
- Format check (CI gate): `dotnet fantomas protocol/src runtime/src sentinel/src sentinel/tests cli/src cli/apps --check`

**Branch:** work on `feat/acp-0.13.6-parity-and-sdk-release` (already pushed; contains the spec). Commit each task separately.

**Capability marker idiom (used by Tasks 3, 4, 5).** For a new capability `X`, add `type XCapabilities = { _meta: JsonObject option }` in the `Capabilities` module and a `decodeXCapabilities`/`encodeXCapabilities` pair cloned from `decode/encodeSessionListCapabilities` (`AcpJson.fs:256-280`), then thread it through `decode/encodeSessionCapabilities` (or `decode/encodeAgentCaps`). **Encode omits the key when `None`.**

**Construction-site discipline.** When a record gains a field, every literal must be updated or the build fails. Each task lists the exact `file:line` sites from the audit. After editing, `grep` to confirm none were missed.

    let private decodeUsage (node: JsonNode) : Result<Usage, string> =
        result {
            let! o = asObject node
            let! usedNode = get "used" o
            let! used = asInt64 usedNode
            let! sizeNode = get "size" o
            let! size = asInt64 sizeNode

            let! cost =
                match tryGet "cost" o with
                | None -> Ok None
                | Some n ->
                    result {
                        let! co = asObject n
                        let! amountNode = get "amount" co
                        let! amount = asFloat amountNode
                        let! currencyNode = get "currency" co
                        let! currency = asString currencyNode

        match u._meta with
        | None -> ()
        | Some meta -> o["_meta"] <- meta.DeepClone()

        o
